# 启动顺序

> [← 返回目录](./README.md)

设备上电后的服务启动顺序：

```
设备上电
  │
  ├─[1] 初始化硬件（Camera、SD Card、Wi-Fi 模块）
  │
  ├─[2] 启动 AP 热点
  │     └─ 网关: 192.168.10.1
  │     └─ DHCP: 192.168.10.100 ~ 200
  │
  ├─[3] 启动 TCP 心跳监听 :9999
  │
  ├─[4] 启动 HTTP REST API 服务 :8080
  │
  ├─[5] 启动 RTSP 预览服务 :8554
  │
  └─[6] 就绪，等待 App 连接
```

**关键：步骤 3（TCP 9999）必须在步骤 4（HTTP 8080）之前或同时启动。**
